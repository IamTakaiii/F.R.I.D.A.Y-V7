# Learn — research

Citations. Not a lesson. Not a quiz.

Load `kernel/io/evidence.md` when making claims.

## Card (≤80)

1. Frame the question (1–2 lines).
2. Gather sources — prefer primary/official; note date.
3. Table: Claim · Source · Confidence · As-of.
4. Conflicts / unknowns.
5. Next checks.

## Persist (optional)

Type `note` at `30 - Knowledge/20 - Notes/YYYY-MM-DD - <Title>.md`. Do not launder `Assumed` into fact.
