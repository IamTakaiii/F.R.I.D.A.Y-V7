# Learn — teach

Chat short. Depth on ask (`why` / `ละเอียด` / practice / quiz).

1. Level-check: at most one question if needed.
2. **Always:** what, in 1–3 plain lines.
3. **On ask:** why · how · common misconception · small practice · sources when non-obvious. Quiz only if asked.
4. Optional lesson: type `note` at `30 - Knowledge/20 - Notes/` (or Learning path under the same notes tree).

Do not open with a lecture outline. One next step beats five sections. Walk-through of a Design stays in the owning `/fr-*`.
