# Brain — inbox

Triage a batch. Prefer ≤10 items per turn.

## Per item

`promote` · `link` · `archive` · `delete`

Promote = rewrite as a registered type at a `schema/placement.md` path (software project note, Knowledge note, Writing, personal module). Project-specific notes stay under the owning project (`89-Notes/`), not `30 - Knowledge/`.

## Steps

1. List Inbox slice.
2. Batch outline → write approval.
3. Apply; remove processed files from Inbox.
4. Do not create `00 - Index.md`.
