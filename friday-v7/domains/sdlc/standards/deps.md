# Deps

Feature List is a roadmap. `mapped` / `planned` ≠ shipped. Load when `depends_on` is unfinished.

Each gap: dep · board status · what we need · strategy (contract-first / stub+flag / port / block / narrow) · queue id that replaces the stub.

Never mark upstream done. Never hardcode around a missing dep without a Design strategy. Ready **R10** fails if a gap has no strategy.
