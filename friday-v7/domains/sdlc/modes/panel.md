# SDLC — panel

Opt-in role panel. Rules live in `kernel/thinking/brainstorm.md` — do not restate them here.
Writes: none (`allow.md`). Panel never locks a Design and never scores a review.

## Run

| Step | Do |
|---|---|
| N | From the arg, else ask. 2–5, default 3. Outside → ask again, no spawn |
| Topic | Caller's own words + cited paths only. No invent |
| Spawn | N disjoint roles, one round, no shared chat |
| Return | Synth keep / drop / tension → hand back to the calling mode |

Partial fail → synth what returned. 0 success → say why, then counsel.
Called bare (`/fr-panel`) with no owning mode → treat the user's topic as the brief.
