# SDLC — decision (ADR)

One software ADR. Not architecture. Not personal (`/fr-life`).

## When

Irreversible or expensive to unwind, or the user asked to record a decision. If the choice is still open, stay in `/fr-design` until lock.

## Card (≤80)

Context (force). Options (≥2) with consequence. Decision + why. Follow-through (what Design/Arch must change).

## Persist

`schema/write-gate.md`. Type `adr`. Path `02 - Decisions/ADR-NN - <title>.md`. Status `accepted` only after the user confirms. Link from Architecture and the affected `design.md` — do not paste the ADR into Design.

## Done

Path + status. If Design now drifts, say so; do not silently rewrite Design here.
