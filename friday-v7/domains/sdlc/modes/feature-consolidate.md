# SDLC — feature-consolidate

Merge duplicate or overlapping **software features**. Preserve history. One canonical name after.

## Identity

`../standards/feature-identity.md`. Same user-visible capability = same feature, even if folder names differ.

## Read

Both (or all) `intent.md` + `design.md` + `queue.md`. List overlaps and unique bits. Do not invent a third product.

## Plan (approve before write)

Keep folder (canonical). Folders to archive. What moves: intent facts, design locks, queue items (re-id if needed). Redirects: Feature List + Overview pointers.

## Persist

Rewrite canonical intent/design/queue via write-gate. Retired folders: add a one-line pointer at top; do not delete history. Update `00 - Overview/02 - Feature List.md`.

## Done

Canonical path + archived paths + queue ids that moved.
