# Personal shape

Not SDLC. No Ready/Done/Ship. Overview uses `brief` + `project_kind: personal`.

## Tree (always)

`20 - Projects/20 - Personal/NN - <Name>/`  
`00 - Overview/` (Brief + optional Goals) · `01 - Plan/` · `02 - Tasks/` · `03 - Decisions/` · `04 - Research/` · `05 - Risk/` · `06 - Outcomes/` · `90 - Log/` · `99 - Archive/`

`enabled_modules` lists **active** work only. Empty folders may exist. Domain extras (`30 - Budget/`, inventory, …) only when needed.

## Shapes

travel · event · home · health · finance · learning · career · creative · self-improvement · admin · mixed

Never invent prices, visa rules, or confirmation numbers. Link a software project only if code is truly separate.
