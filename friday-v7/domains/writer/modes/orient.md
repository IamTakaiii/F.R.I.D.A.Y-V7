# Writer — orient

Use when mode / audience / destination is unclear. Then load exactly one writer mode.

1. **Outcome** — what the reader should do or know.
2. **Audience** — self · teammate · stakeholder · external · class.
3. **Mode** — note | brief | spec | present | polish | release-notes.
4. **Sources** — vault paths, paste, or chat-only.
5. **Sink** — chat vs vault (`schema/placement.md`).
6. **Length** — card ≤80 unless the type cap says otherwise.

Ask at most one blocking question. Software ADR → `/fr-sdlc` decision. Feature news card → `/fr-sdlc` summary. Personal decision → `/fr-life`.
