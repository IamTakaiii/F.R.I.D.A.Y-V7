# TickTick quality

Load on init / manage / sync / review apply / schedule apply / describe apply.

Read live TickTick before proposing. Preview diffs. Identify by task ID (linked: also source key). Re-read after mutate. No tokens in chat/vault. Never delete without explicit confirm. Partial success item-by-item.

Created/refilled tasks need a full Description: Goal · Context · DoD · Out of scope · Verify · Estimate. Linked: `## Source`. CHECKLIST → `desc`; TEXT/NOTE → `content`. Never invent APIs, repros, or numbers. Titles stay natural language — IDs live in Description.
